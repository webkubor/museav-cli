## 1. 先定边界

本期不把原型的官网内部 `sitePage = discovery` 状态搬到控制台。控制台已是公开模型广场唯一实现，`/models` 由 `PublicShell` 承载，需使用真实 URL，让刷新、返回、复制链接和详情回退都稳定。

- **模型广场列表**：`/models`
- **模型发现**：`/models/discovery`

`/models/discovery` 必须在 `:modelId` 参数路由之前声明，避免 `discovery` 被当成模型 ID。

不包含：#822 详情描述宽度老需求、新手指南、管理后台、#818 的生产配置写入。

## 2. 入口、CTA 与路由

### 2.1 模型发现的唯一产品入口

模型发现是模型广场的分析视图，不是控制台左侧菜单、也不是顶栏新增一级导航。

> **2026-09-03 修订**：入口位置与形态改回 PRD 原型。本节原先规定「放页面标题行右侧、
> `variant="outline"`」，理由是「避免和列表筛选语义混淆」—— 但原型
> （`marketplace-discovery-entry`）里它就在搜索 + 排序同一行的最右，且是**品牌色强调**。
> 需求方 2026-09-03 指出实现与 PRD 不一致。按本文档「定稿口径」自己写下的那条
> （**PRD 原型 > 飞书文档 > 现代码，原型优先不需要额外授权**），这段文字 spec 让位于原型。
> 「语义混淆」那条论证不成立：原型把它和搜索/排序放一行恰恰是因为三者都是「怎么找模型」，
> 而标题行是页面身份区。

入口放在**公开模型广场 `/models` 搜索 + 排序工具栏（`.models-toolbar`）的最右**：

```text
[🔍 搜索模型名、API ID 或厂商…]   [推荐排序 ▾]   [📊 模型发现 →]
```

- 组件：现有 `Button`，`variant="brand-outline"`、`size="sm"`；不可手写按钮。
  `brand-outline` 是 2026-09-03 为此新增的变体（品牌色描边 + 8% 浅底 + 品牌色文字，
  配比取原型实测，用 `--brand-*` 表达以跟随双市场与明暗主题）——
  它不是页面主操作（用 `brand` 实底会抢掉真正的主操作），但也不能降成中性 outline。
- 图标：`LuChartColumn`（**柱状**，对齐原型的 `BarChart3`，不是折线 `LuChartLine`）
  + 尾部 `LuArrowRight`（原型有，表示进入新页面）。
- 文案：`模型发现`；不写“数据分析”“排行榜”等泛化文案，保持与 PRD 页面名称一致。
- 窄屏：随工具栏 flex 换行，不使用悬浮按钮，不遮挡现有右下角“更多筛选”。
- 点击：`navigate('/models/discovery')`；不需要登录、不弹确认框；进入页先显示页面骨架，再按默认 `Agent` 内容就绪。
- 埋点：`marketplace_discovery_entry_clicked`，payload `{ source: 'catalog_toolbar' }`
  （位置已从标题行改到工具栏，source 随之改；只记录点击，不将加载成功伪报为点击）。

**不新增其他入口：**

- 不在全站顶栏、登录态左侧导航、模型体验页、卡片“去体验”旁重复放“模型发现”，避免公开模型广场和控制台业务导航混层。
- 精选轮播、普通模型卡仍只保留详情 / 去体验 / 对比 / API 请求等既有动作；不在每张卡增加第 4 个操作。

## 4. 路由与回退行为

### 4.1 发现页 URL 状态

可分享、刷新后应该保留的“页面筛选/视图”状态进入 query；短生命周期展示状态保留在组件内，避免 URL 被模型勾选、浮层开关等噪声污染。

```text
/models/discovery?
  modality=agent|text|image|video|audio
  &task=<当前模态合法任务>
  &scope=all|supported
  &ranking=overall|value|usage|price
  &providers=<逗号分隔的 provider>
  &access=all|supported|pending
  &page=<完整榜单页码>
```

规则：

1. 缺省 URL 等价于 `modality=agent`；Agent 是默认首 Tab。
2. `task` 只在该 `modality` 有二级任务时有效；`agent` 忽略 task，并始终使用 `Agent` 数据。
3. 参数非法、任务不属于模态、页码非法：静默归一到该模态首个合法值，并 `replace` URL；不显示错误 toast。
4. Tab/任务/范围/榜单筛选变更时更新 URL，不新增浏览器 history 条目（`replace`）；用户在“模型发现”和详情之间往返不应堆积十几条历史记录。
5. 图表坐标轴、优选区、已勾选的散点模型、下拉/Popover 开关、Agent 榜展开状态、各运行图表的周期为**本地 UI 状态**，刷新后回默认，不进 URL。

### 2.2 从发现页进入详情、返回发现页

- 已接入且有详情的模型行 / Top 5 行 / 完整榜单行：进入 `/models/:slugOrId`。
- 导航 state 传：

```ts
{
  source: 'discovery',
  fromDiscoverySearch: location.search,
  fromDiscoveryScrollY: window.scrollY,
}
```

- 详情页返回按钮：若来源是 `discovery`，返回 `/models/discovery${fromDiscoverySearch}`，页面恢复离开时的 scrollY；其余来源维持现有“返回模型广场”逻辑。
- 暂未接入模型：行不伪装成可跳转；显示“暂未接入”状态，不能触发详情导航。若后续纳入外部模型跳转，须单独由产品确认跨站行为，当前不自行添加。
- “返回模型广场”：从发现页回 `/models`，不携带发现页的分析筛选状态。

### 2.3 详情页区块顺序

```text
Hero / 规格
→ API 接入
→ 平台运行表现
→ Benchmark 基准评测
→ 相关模型
```

所有区块继续使用独立 `.mg-tile.mg-detail-card`，不把详情改成一张长卡；卡片视觉、边界、间距以现有 `catalog-detail.css` 为准。

## 3. 模型发现页信息架构与交互状态机

### 3.1 页面骨架

```text
页面头：模型发现 + 数据快照 + 返回模型广场
一级 Tab：Agent | 文本 | 图像 | 视频 | 音频
二级任务：仅非 Agent 显示
范围切换：全部行业模型 | 仅看已接入

Top 5 + 摘要卡
专项指标排行
模型能力多维分析
完整指标榜单
热门 Agent 排行（仅 Agent）
```

视觉实现遵循控制台：

- 一级导航：`Tabs` 的 `underline` variant；不复制原型自定义按钮条。
- 主内容块：`.mg-tile` 实心卡；不做渐变大 Hero、不做原型式装饰色块。
- 模型/厂商身份：`ModelIcon`；**仅热门 Agent 排行**按 PRD 显示应用名首字符。
- 图表：复用 `recharts`、现有用量页的 Tooltip、cursor、轴线和响应式容器做法；不复制原型手搓 SVG。

### 3.2 一级 Tab 状态迁移

| 用户动作 | 状态变化 | 可见反馈 |
|---|---|---|
| 点击 Agent / 文本 / 图像 / 视频 / 音频 | 更新 `modality` 与 URL；任务归一为该模态第一个合法任务 | active underline 立即切换；内容区域局部 skeleton 后显示对应模块 |
| 切到 Agent | `task='Agent'`；隐藏二级任务栏 | 页面不留下一个只有“Agent”的冗余 Tab |
| Agent → 文本 | `task='文本对话'` | 文本二级任务栏出现，首项激活 |
| 切换一级 Tab | 重置坐标轴、榜单指标、厂商筛选、接入筛选、榜单页码、散点勾选为新模态默认值；**范围 scope 保持** | 防止旧模态筛选污染新模态；不 toast |

### 3.3 二级任务和范围

- 文本：`文本对话 / 代码生成`；图像、视频、音频沿 PRD 当前任务集。
- Agent：没有二级任务栏。
- 切任务：重置分析坐标、榜单指标与页码；音频任务额外重置散点默认模型集。
- 范围切换（全部行业模型 / 仅看已接入）：不改变 Tab/任务；影响 Top 5、专项排行、散点和完整榜单。
- 若“仅看已接入”无数据：保留当前控件状态，内容区显示空态 + “切换到全部行业模型”按钮；点击按钮立刻切回 `scope=all`。

### 3.4 Top 5、摘要、专项排行

- Top 5 每行已接入模型可点击/Enter/Space 进入详情；行 hover 只做现有 `.mg-tile-hover` 级别反馈，不制造新动效。
- “查看更多”将完整榜单指标恢复为“综合评价”、页码重置为 1，并平滑滚到榜单标题；移动端同样生效。
- 摘要卡的指标说明使用 `InfoTip`，hover 和键盘 focus 均可读。
- 专项排行柱：hover/focus 给紧凑 Tooltip；“单次任务成本”显示总成本和五项组成。Tooltip 仅解释数值，不触发跳转。

### 3.5 多维分析

| 控件 | 行为 | 反馈 |
|---|---|---|
| 预设（质量×成本等） | 一次设置 x/y 轴组合 | 激活态立即变更，散点无整页 loading |
| x/y 指标 Select | 单轴切换 | Axis 标题、刻度和 Tooltip 同步更新 |
| 优选区 | 本地布尔开关 | 用低对比品牌色区域标出“优选区”；禁用仅隐藏区域，不重排点 |
| 模型筛选 Popover | 搜索、勾选/取消、清空、全选、恢复默认 | 显示 `N / 总数`；勾选变更立即重绘；0 条时显示“请选择至少一个模型” |
| 散点 | hover/focus 显示模型与双轴原值 | 点不导航，避免分析时误离页 |

Popover 用现有 `Popover` / `Combobox` 能力，不在页面自行实现浮层层级、焦点管理或关闭逻辑。

### 3.6 完整指标榜单

- 指标类型 / 厂商多选 / 接入状态 / 分页由 URL 驱动。
- 厂商筛选打开后允许多选；“重置”清空选择；“完成”只关闭浮层，筛选已即时生效。
- 筛选结果为空：保留筛选条件，显示 `EmptyState` 与“清空筛选”操作。
- 行点击与 Top 5 一致；行内“查看详情”是显式入口；暂无详情的行禁用，标签保持可读。
- 切换筛选或指标时页码归 1，避免落在没有数据的旧页码。

### 3.7 热门 Agent 排行

仅 `modality=agent` 渲染。

- 周期：`本日 / 本周 / 本月`，默认本日；周期为本地状态。
- 展示：默认 Top 10，“查看更多”展开至 Top 20，“收起”回到 Top 10。
- 切周期：保留展开/收起状态；直接取该周期静态排序快照，**不在前端跨周期重新算名次**。
- 行无跳转；应用图标是应用名称首字符，不使用 OpenRouter Logo。
- 桌面两列、窄屏单列；始终按 1–20 连续阅读顺序。

## 4. 详情页：平台运行表现

### 4.1 卡片结构

运行表现为单独 `.mg-tile` 区块，内部桌面 2×2，窄屏单列。每张指标卡：

```text
指标名称 + InfoTip                 独立时间范围分段控件
当前值 + 单位
较上一等长周期的变化
趋势图（Recharts） + hover/focus Tooltip
```

按模态映射标签：文本为 Token / TTFT / 输出 TPS；图像、视频、音频使用各自任务语义。所有趋势变化除了颜色还需 `+/-` 和文字描述；耗时下降是正向反馈。

### 4.2 周期切换

- 使用量：设计 spec 规定 `1W / 1M`，默认 `1M`。
- 成功率、响应耗时、处理速度：设计 spec 规定 `1D / 1W`，默认 `1D`。
- **每张卡自己的周期 state，互不影响。**
- 切换时只替换这一张卡的数值和曲线，卡内显示骨架，其他三卡不闪烁。
- hover/focus 数据点 Tooltip 显示完整时间、数值、单位；无数据时显示“该时段暂无数据”。

### 4.3 反馈状态

| 状态 | 呈现 | 行为 |
|---|---|---|
| 首次加载 | 区块内 4 张与最终高度一致的 skeleton | 不阻塞 Hero/API/相关模型 |
| 单指标无数据 | 保留该指标卡，显示“暂无足够平台数据” | 不显示伪造 0、无同比 |
| 所有指标无数据 | 区块级空态“该模型暂无平台运行数据” | 不渲染四个空卡 |
| 15 分钟以上未更新 | 标题右侧 warning 文案“数据更新延迟”+ 实际更新时间 | 保留最后有效数据 |
| 请求失败 | 区块级 `EmptyState` 错误态 + 重试按钮 | 不影响详情其他区块；有旧缓存时保留旧值并显示刷新失败提示 |

## 5. 详情页：Benchmark 基准评测

### 5.1 展示和交互

Benchmark 是只读模块，无筛选、无排序、无跳转：

1. 标题 `Benchmark 基准评测` + **只出现一次** `Artificial Analysis` 来源标签；
2. 摘要卡按实际数据显示，最多三列：得分、指标、行业排名、领先百分位、分布位置；
3. 分类评测双列卡：分类标题、评测项说明、进度条、结果；
4. 窄屏摘要卡/分类卡都变单列。

不复刻 Artificial Analysis 页面，不以 ModelGo 自身模型全集重新计算排名/百分位。

### 5.2 缺失与反馈规则

- 缺少一个 summary/evaluation：隐藏那一项，绝不补“—”占位。
- group 没有 evaluation：隐藏整个 group。
- `summaries` 和 `groups` 都为空：整个 Benchmark 区块 `return null`，详情直接接相关模型，不留标题或空卡。
- Mock 阶段也必须覆盖：文本、Agent、图像、视频、TTS、STT、有数据模型、全无数据模型。
- Benchmark 仅是静态/Mock 数据时，不显示“实时”“最新”；更新时间只在数据源明确下发时展示。

## 6. 反馈与可访问性统一要求

- 所有切换控件：使用语义 Tabs、radio group 或已有 SegmentedToggle；Tab 有 `aria-selected`，分段有 `aria-pressed`/radio 语义。
- Tooltip 触发必须同时支持 hover 和键盘 focus；纯图标的说明必须有可访问名称。
- 交互后的正常反馈以**状态变化本身**为主：active 态、局部 skeleton、数据/图形更新；不为普通 Tab 切换滥发 toast。
- toast 只用于用户主动提交且异步失败/成功的写操作；本期发现/详情均为只读，没有普通成功 toast。
- `prefers-reduced-motion` 下关闭卡片位移、图表/Tab 非必要动画。
- 390px 校验：顶部 Tabs 可横向可访问且不压缩文字；图表不横向压缩而单列；表格保留横向滚动容器；浮层不超视口。

## 7. 原型与文字 spec 的冲突 —— 已按原型定稿（2026-08-25）

**结论：三处全部以原型代码为准，不再等确认。** 依据两条：

1. **原型比 spec 新 13 天**：`MarketplaceRuntimeMetricsPanel.tsx` / `MarketplaceBenchmarkPanel.tsx` 最后改动 **08-24 12:19**（`15cbbe7`），而 `2026-08-11-marketplace-model-runtime-metrics-design.md` 停在 **08-11 10:18**（`a8169cb`）。
2. **仓库铁律本就是「PRD 原型 > 飞书文档 > 现代码」**，原型优先不需要额外授权。

原文档里"优先建议采用文字 spec"的判断作废 —— 那是在不知道两者新旧关系时写的。

### 定稿口径

| 项目 | 采用值 | 出处 |
|---|---|---|
| 全部四个指标的周期档 | **`1D / 1M`**（无 `1W`） | `marketplaceRuntimeMetrics.ts:169-177` |
| 使用量默认档 | `1M` | 同上，`usage.defaultRange` |
| 成功率 / 耗时 / 速度默认档 | `1D` | 同上 |
| 使用量是否产生缺失点 | **不产生** | `createSnapshot(..., config.key !== "usage")` —— `allowMissing` 实参 |
| 其余三指标缺失点 | **产生，渲染为断线** | 见下 |

### 缺失值：按 `number | null` 实现，不要照抄 mock 的 `0`

原型数据层把缺失点写成 `value: 0` + `missing: true`（`marketplaceRuntimeMetrics.ts:140-141`），但**这是 mock 生成的简化，不是设计意图**。判断依据是渲染层专门为 `null` 实现了一整套处理：

```
MarketplaceRuntimeMetricsPanel.tsx
  :9    value: number | null          类型本身允许 null
  :47   flatMap 时跳过 null           算极值不被缺失点污染
  :57-58 向前/向后找最近有效值        缺口两侧插值定位
  :93   null 点不参与坐标计算
  :121-126 solidPaths 在 null 处分段  → 线断开，不是画到 0
```

如果设计意图是 `0`，这套 null 处理逻辑没有存在必要。所以前端按 `number | null` 落地：缺失用 `null`、图表在缺口处断线、Tooltip 显示「该时段暂无数据」（§4.3 已有规定）。**不要把缺失渲染成 0**，那会让成功率/耗时图出现虚假的断崖。
