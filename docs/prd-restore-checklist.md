> **目的**：不是修单个 bug，是提炼「我还原 PRD 时的系统性盲区」，前置到 1.0.7 开工，避免重犯。
> **生成**：2026-09-21，多 agent 并行根因分析。

## 一、结论先行

31 条核心单里 **23 条根因是「前端还原 PRD 遗漏」**（另 8 条是后端/环境/误报/健壮性，非还原问题）。盲区分布：

| 高发度 | 盲区维度 | 条数 | 一句话 |
|:---:|:---|:---:|:---|
| 🔴🔴🔴 | **状态机/交互流程漏了** | **10** | 还原了「主流程 happy path」，漏了 PRD 里的分支/回退/跳转参数/入口互斥 |
| 🟠 | 信息层级/图标/字段错 | 3 | 嫌难排版擅自砍字段、对标旧版原型、成对字段漏渲 |
| 🟡 | 照搬原型实现的坑 | 2 | 裸标签后代选择器越界、照搬原型窄列宽在真数据下截断 |
| 🟡 | 空态/失败态/边界漏了 | 2 | 违反「不补空卡」、限高滚动没在真实行数下验 |

| ⚪ | 窄屏/响应式、埋点、健壮性、数据口径 | 各 1 | — |

**外加国际站文案簇 27 条**（#439–462 一整批）：英文文案没改写、原生控件没换、下拉透明度——**这是一个独立的、量最大的系统性盲区：做国内站时完全没考虑国际站的文案/控件还原。**

## 二、两个最痛的系统性盲区（1.0.7 必须堵）

### 盲区 A：只还原主流程，漏 PRD 的「分支 / 回退 / 跳转 / 互斥」（10 条，最高发）

这是最花钱的盲区。典型例子：
- **#1003** hash 路由只做了「命中白名单就定位」，PRD §13.3 要求的「非法值回退 #overview」「模态不可用回退」两条分支**从未实现**
- **#1016** `integrated_site` 有多个枚举值，我只做了一条点击分支，其他枚举落到 no-id 分支弹自相矛盾提示
- **#716 / #556** 跨页跳转没带 PRD 要求的上下文参数（dimension / 选中空间），只跳页顶或跳到已删除的孤儿路由
- **#633** 破坏性操作「删除」按 PRD §7.4 该收进详情抽屉，我渲染进了列表行内
- **#1070** 恢复旧卡时只看单张原型截图，漏了 onboarding spec 的「新入口替代旧卡、不并存」互斥约束
- **#930** 相对时间窗被 useMemo 冻死，刷新不重算 —— 交互的「时间维度」漏了

**共性**：PRD 里"非 happy-path 的部分"——回退分支、每个枚举的独立处理、跳转要带的参数、入口之间的互斥关系、刷新/重取数的时间重算——这些**在原型截图里看不出来，只在 PRD 文字规则里**，我还原时习惯性只照着"能跑通的主路径"做。

### 盲区 B：做国内站时完全不考虑国际站还原（27 条文案簇）

一整批 `[国际站]` 单：英文文案没改写（沿用中文直译或旧文案）、时间选择器是**浏览器原生中文控件**、下拉透明度问题、首字母大小写、复数形式、术语统一（Guardrail hit → Guardrail Triggered）。

**共性**：国际站不是"国内站翻译一下"，PRD 对国际站有独立的**文案表 + 控件要求**，我做的时候按国内站一套走完就交了，国际站整个是补测出来的。

## 三、1.0.7 开工前 Checklist（每个页面/模块动手前逐条过）

### A. 交互流程（对着 PRD **文字规则**过，不是对着截图）
- [ ] **每个枚举值都有独立处理分支**？（`integrated_site`/状态/类型等，禁止"合并同判"）
- [ ] **PRD 里的回退/兜底分支都实现了**？（非法 hash、目标不存在、模态不可用 → 各自的回退 + 埋点）
- [ ] **每个跳转入口**：目标路由存在？带了 PRD 要求的全部上下文参数（dimension/空间/Tab）？落到目标区块而非页顶？
- [ ] **破坏性操作**（删除/轮转/停用）按 PRD 放对位置？（多数收进详情抽屉，不在列表行内）
- [ ] **入口互斥关系**？（新入口是否该"替代"旧入口而非并存 —— 查 spec 不是查截图）
- [ ] **相对时间窗**（近 N 天/今日/本月）：刷新/重取数时以**当前时刻**重算 from/to，不复用挂载值？
- [ ] **超过 20 项的筛选/选择列表**：有搜索框即时过滤？

### B. 字段 / 信息层级（以 PRD 原型**最新 commit** 为准）
- [ ] 开工前**核对 PRD 原型最新 commit**，字段口径以定稿版为准（#1064 就是对标了旧版）
- [ ] **成对/多值字段全部渲染**？（输入价 + 输出价、上下文 + 缓存价，别只渲一半）
- [ ] **图表轴/刻度还原原型全部标签字段**？（长文本用 ellipsis+title，**禁止因难排版擅自删字段** —— #1065）
- [ ] 卡片时间粒度标签（今日/本月）与**取数窗口口径一致**？

### C. 空态 / 边界 / 健壮性
- [ ] 可为 null 的指标卡/明细行按 PRD 空态规则**隐藏**，不补"暂无数据"占位卡（#1005 §11.2）？
- [ ] 限高滚动前，确认真实**最大行数**能否自然撑开，收起态默认不限高？
- [ ] 详情/护栏守卫判**字段有内容**（`Array.isArray`/`Object.keys>0`）而非"对象非空"，并给无权限/已删除空态？

### D. 视觉 / 样式移植
- [ ] 选中态变底色的容器（Tab/pills）内，图标/文字**逐状态验对比度**（#1080 蓝底蓝图标）？
- [ ] 移植原型样式**禁用裸标签后代选择器**（`.x span{}`），钉到单类名或用 inherit（#1069 两色裂开）？
- [ ] 会截断的文本在**真实长数据**下用 OverflowTip 气泡兜底，不只靠原生 title（#1012 70 字模型名）？
- [ ] 表格页在 **768px 用真实最长数据**验证：不截断 + 有横向滚动容器（#1006）？

### E. 国际站（做国内站的同时就要做，不是补测）
- [ ] 所有文案走**国际站文案表**，不是国内站直译？（术语统一、首字母大写、复数形式）
- [ ] **禁止原生控件**（时间选择器/下拉），用 `ui/*` 组件（原生控件是浏览器中文 + 半透明）？
- [ ] 交付前对**渲染后 DOM 全页扫描**：不得出现裸 i18n key（点号分隔的英文串，#491）？
- [ ] 含第三方数据的模块，逐字核对页面文案**不出现 PRD 禁列的来源名/副标题**（#1004 openrouter）？

### F. 埋点
- [ ] 曝光/滚动类埋点**不依赖渲染管线**（IO/rAF），用定时器轮询几何量，保证后台标签页也上报（#1007）？

## 四、可门禁化的规则（落 ui-guard / 校验脚本，见 §五）

按你的原则「约定做成门禁不是文档」，下面几条**能被机器静态/运行时检查**，应落成门禁而非只写在这份 checklist 里：

| 规则 | 门禁方式 | 对应 bug |
|:---|:---|:---|
| 禁裸标签后代选择器 `.x span{}` | 静态扫 CSS（check-css-tokens 扩展） | #1069 |
| 禁原生 `<select>`/原生时间控件 | ui-guard 已有，扩到时间控件 | #456 等 |
| 渲染后 DOM 无裸 i18n key | ui-runtime-audit 新增一项 | #491 |
| 表格页 768px 有横向滚动容器 | ui-runtime-audit 已有横向滚动项，补"真实长数据" | #1006 |
| 选中态容器内图标对比度 | ui-runtime-audit 新增对比度项 | #1080 |

## 五、门禁落地结果（诚实记录）

| 规则 | 落地？ | 说明 |
|:---|:---|:---|
| **禁原生日期/时间控件**（#456） | ✅ **已落 `ui-guard.sh` BLOCK 6** | `<input type="date/time/datetime-local/month/week">` 由系统渲染（国际站出中文控件）。判据干净、存量零误伤、注释行已过滤。 |
| 禁裸标签后代选择器（#1069） | ❌ **不落门禁**（留人工 checklist） | 存量 129 处几乎全合法（`.header h2` 是正常 CSS）；#1069 的坑是"后代选择器碰巧覆盖带语义色的子元素"，静态规则**区分不了合法与越界**，强做 = 129 处误伤。**做不成干净门禁的不硬塞。** |
| 裸 i18n key 扫描（#491） | 🔶 **待落 ui-runtime-audit** | 渲染后 DOM 出现"点号分隔英文串"→ 判据清晰，下一步加进 runtime-audit。 |
| 表格 768px 横向滚动（#1006） | 🟡 已部分覆盖 | ui-runtime-audit 已有横向滚动项，需补"用真实最长数据"。 |
| 选中态图标对比度（#1080） | 🟡 待评估 | 对比度可算，但要先确认判据不误伤。 |

> **落地原则**：能做成**干净判据**（零误伤 + 抓得准）的才落门禁；做不成的留在 §三 checklist 做人工检查项——满屏误报的假门禁比不做更糟（大家会学会无脑豁免）。
