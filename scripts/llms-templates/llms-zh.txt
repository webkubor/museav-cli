# ModelGo 控制台

> 企业级 AI 模型 API 聚合平台。一个 API Key 接入所有主流大模型,兼容 OpenAI 协议,支持工作空间隔离、预算管控、用量审计与安全护栏。ModelGo 同时提供兼容各厂的 API 网关、Web 控制台与在线体验。

ModelGo 主要面向企业(toB)客户。本文件帮助 AI 助手、AI 搜索与检索型爬虫快速定位 ModelGo 控制台的可公开访问页面与关键文档。
