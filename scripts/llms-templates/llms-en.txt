# ModelGo Console

> Enterprise-grade AI model API gateway. One API key for every major LLM, OpenAI-compatible, with workspace isolation, budget controls, usage auditing and guardrails. ModelGo provides the API gateway, web console, and online playground under a unified platform.

ModelGo serves enterprise (B2B) customers. This file helps AI assistants, AI search engines, and retrieval crawlers locate the publicly accessible pages of the ModelGo console quickly.
